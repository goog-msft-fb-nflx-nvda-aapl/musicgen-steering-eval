# musicgen-steering-eval

course final project for CommE5070 (deepmir, ntu). music generation track, solo.

question: when you steer musicgen with a concept direction (notes, chord quality, tempo), does the effect survive evaluators that share nothing with the probe the direction came from, and does picking layers by probe decodability pick the layers where steering works?

builds on musicgen (frozen) and the musicrfm codebase. no generator training. see PLAN.md for design, WORKLOG.md for what has been run.

status: planning (2026-10-05).
