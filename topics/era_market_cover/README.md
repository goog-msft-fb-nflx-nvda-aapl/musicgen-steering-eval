# Era and release market cues, and cover-song generation

Topic offered by the course TA as a team-finding example (extension of HW1): which parts of a song (vocals, accompaniment, full mix) let a model recognize the release era and the release market, what the model actually learned (language, arrangement, recording style, or dataset bias), and whether stable era cues can control a generated cover so that it keeps the original melody and shows the target era's style.

Status: literature survey (not started on experiments).
